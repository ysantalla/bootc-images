# Brand glyphs

One-colour marks of applications, used by `katze-mono.py` before any other
source. `aliases.toml` points each application at one of these by file name.

The solid ones (Android Studio, Bambu Lab, DBeaver, GIMP, MongoDB, mpv, OBS,
Postman) come from [Simple Icons](https://simpleicons.org) 16.38.1, unchanged,
and most are drawn as their contour (`[outline]` in `aliases.toml`).
The collection is CC0-1.0; the marks themselves remain trademarks of their
owners. To add one, save `https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`
here and add an alias.

Files ending in `-line` are drawn with lines. They come from
[Arcticons](https://github.com/Arcticons-Team/Arcticons), through the Iconify
API, unchanged. Arcticons is CC-BY-SA-4.0: a published theme that includes
them must credit Arcticons and keep that licence for them.

`zed-line.svg` was drawn for this project: Zed's own mark, traced along the
centre of its lines so that it can be drawn thinner. No line version of it
exists in either collection.

The other `-line` files (`android`, `aperture`, `cast`, `calculator`, the `generic-*`
category glyphs and the like) come from [Tabler Icons](https://tabler.io/icons)
3.52.0, unchanged. Tabler Icons is MIT. `file-text-line.svg` is Tabler's
`file-text` as it was on the project's main branch on 2026-11-24.

`dolphin-line.svg` was also drawn for this project: the folder and dolphin of
Dolphin's own icon (`org.kde.dolphin.svg`, from KDE's Dolphin, GPL-2.0-or-later),
with the dolphin's outline traced from it.
